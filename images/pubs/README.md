# 论文配图

将图片放在本目录，再在 `_pages/publication.md` 对应卡片的 `image` 字段填写文件名。
支持 PNG、JPG、WebP 等浏览器支持的图片格式。图片会完整显示，不裁剪。

当前预设文件名：

- `hoi-dyn.png`
- `aff3dfunc.png`
- `segmo.png`
- `coordination.png`
- `dynamic-to-static.png`
- `place-recognition.png`
- `electrode-localization.png`

图片不存在时显示占位区域；添加或更换图片后重新构建 Jekyll 即可。
每篇论文只配置一次。`tags` 支持英文逗号分隔的多个标签，筛选按钮和数量自动生成。
`description` 是可选简介；留空不显示。`paper`、`project`、`code` 均为可选链接。
