# 访问与工作经历 Logo

将以下图片放在本目录，重新构建网站即可自动显示：

- `cmu.png`：Carnegie Mellon University
- `tum.png`：Technical University of Munich
- `huawei.png`：Huawei
- `arcsoft.png`：Arcsoft
- `deecamp.png`：Sinovation Ventures / DeeCamp
- `xiaomi.png`：Xiaomi

支持 PNG、JPG、SVG、WebP；如果使用其他文件名或扩展名，请修改 `_pages/experience.md` 中对应的 `logo` 路径。图片未提供时显示机构简称。建议使用透明背景的官方 logo，图片保持比例完整显示。
